# 🚌 Транспортный справочник (Transport Catalogue)

## 📖 О проекте

**Transport Catalogue** — это высокопроизводительная система для моделирования и анализа маршрутов общественного транспорта. Проект реализован на **C++17** и предоставляет полноценный бэкенд для работы с остановками, автобусными маршрутами, поиском оптимальных путей и визуализацией карты в формате **SVG**.

Система способна обрабатывать большие объёмы данных, строить граф транспортной сети, учитывать время ожидания и движения, а также выдавать детальную информацию по запросам — от статистики маршрутов до построения маршрута «от точки А до точки Б».

---

## 🎯 Основные возможности

### 📂 Загрузка и обработка данных
- **Поддержка JSON** — все входные данные (остановки, маршруты, расстояния, настройки рендеринга и маршрутизации) загружаются из единого JSON-файла.
- **Гибкая структура запросов** — отдельные блоки для `base_requests` (построение базы) и `stat_requests` (выполнение запросов).

### 🚏 Управление транспортной сетью
- Добавление остановок с географическими координатами.
- Добавление автобусных маршрутов (кольцевых и некольцевых) с указанием последовательности остановок.
- Установка расстояний между остановками (в метрах) для точного расчёта реальной длины маршрута.

### 🧮 Расчётная аналитика
- **Длина маршрута** — вычисление как географической (по сфере), так и реальной (по дорожным расстояниям).
- **Коэффициент извилистости** — отношение реальной длины к географической.
- **Количество остановок** — общее и уникальное на маршруте.
- **Статистика по остановке** — список автобусов, проходящих через неё.

### 🗺️ Визуализация карты (SVG)
- Автоматическая генерация **SVG-изображения** схемы маршрутов с использованием:
  - Линий маршрутов с уникальными цветами (из палитры).
  - Подписей названий маршрутов и остановок.
  - Кружков для остановок.
- Поддержка пользовательских настроек отображения (размеры, отступы, цвета, шрифты и т.д.).

### 🧭 Поиск оптимального маршрута
- Построение **графа** транспортной сети, где вершины — остановки (разделённые на «ожидание» и «посадку»), а рёбра — время ожидания и время поездки между остановками.
- **Алгоритм Дейкстры** (с предварительным вычислением всех пар) для нахождения кратчайшего пути по времени между двумя остановками.
- Выдача подробного маршрута с указанием:
  - Этапов ожидания автобуса на остановке.
  - Этапов поездки с указанием автобуса, количества промежуточных остановок и времени в пути.

## 🛠️ Технологический стек

- **Язык**: C++17 (стандартная библиотека, шаблоны, алгоритмы).
- **Сборка**: CMake (не показан, но подразумевается).
- **Формат данных**: JSON (собственный парсер и билдер).
- **Визуализация**: Генерация SVG-документов.
- **Графы**: Реализация взвешенного ориентированного графа с оптимизацией памяти.
- **Геометрия**: Расчёт расстояний по сфере (формула гаверсинусов).

## 🏗️ Архитектура проекта

Проект построен по модульному принципу:

| Модуль               | Назначение |
|----------------------|------------|
| `transport_catalogue`| Хранение и управление данными об остановках, маршрутах и расстояниях. |
| `geo`                | Геометрические вычисления (расчёт расстояний). |
| `graph`              | Построение графа транспортной сети и предварительный расчёт кратчайших путей (алгоритм Дейкстры для всех пар). |
| `transport_router`   | Интерфейс для поиска маршрута между остановками. |
| `json` / `json_builder` | Парсинг и сериализация JSON с удобным строителем (fluent-интерфейс). |
| `json_reader`        | Чтение JSON-запросов и их выполнение (загрузка базы, выполнение статистических запросов). |
| `map_renderer`       | Генерация SVG-карты по заданным настройкам и данным каталога. |
| `svg`                | Базовые классы для построения SVG-элементов (круги, ломаные, текст). |
